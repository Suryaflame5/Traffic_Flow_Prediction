# Traffic Flow Prediction

## Overview

Smart city traffic forecasting AI system.

A complete end-to-end machine learning application built with modern AI engineering practices.

---

## Features

- Machine learning pipeline
- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Prediction API
- Interactive dashboard
- Data visualization
- FastAPI backend
- React frontend

---

## ML Workflow

```
Dataset
  -> Data Cleaning
  -> Feature Engineering
  -> Model Training
  -> Evaluation
  -> Saved Model
  -> FastAPI Prediction API
  -> Interactive Dashboard
```

## Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
